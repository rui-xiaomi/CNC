# PRD 片段：状态策略

> 用法：复制本文件中 `### 状态策略` 开始的内容到 PRD 正文，并放在 `### Surface 清单` 之前。根据项目实际规则替换所有 `待确认`，不适用状态保留并说明理由。

### 状态策略

| 状态 | 业务判定 | 可观察呈现 | 允许操作 | 恢复路径 | 持久化 |
|---|---|---|---|---|---|
| `default` | 数据可用且无进行中操作 | 正常内容 | 按权限开放 | — | 否 |
| `loading` | 首次或重新加载数据 | 相关区域显示加载指示 | 允许导航；禁止重复加载 | 成功进入 default；失败进入 error | 否 |
| `empty` | 查询成功但无数据 | 空状态说明与主操作 | 允许新建/刷新 | 创建成功或刷新有数据 | 否 |
| `error` | 当前操作失败且可恢复 | 人话错误、重试和详情入口 | 保留安全的查看/导航 | 重试成功或取消 | 否 |
| `disabled` | 前置条件不满足 | 控件禁用并说明原因 | 不允许触发该操作 | 前置条件满足 | 否 |
| `offline` | 连接监控连续失败达到阈值 | 状态栏常驻离线标识；必要时横幅 | 已加载数据只读；禁止写入 | 自动或手动重连成功 | 否 |
| `busy` | 后台或长任务进行中 | 局部进度；超过阈值提供取消 | 未受影响区域可操作 | 完成、失败或取消 | 否 |
| `dirty` | 可编辑数据与最后保存版本不同 | 标题或工具栏显示未保存 | 允许保存/放弃；关闭和导航需拦截 | 保存或放弃 | 按项目决定 |
| `readonly` | 有查看权但无修改权，或离线降级 | 字段可查看复制但不可编辑 | 查看、复制、导出按权限开放 | 权限或连接恢复 | 否 |
| `validating` | 异步校验尚未完成 | 字段旁显示校验中 | 禁止提交；允许继续编辑 | 校验成功或显示行内错误 | 否 |

#### 全局规则

- `busy` 与 `loading` 分开：`busy` 是操作进行中，`loading` 是数据尚不可用。
- `readonly` 与 `disabled` 分开：只读内容仍可查看和复制；禁用操作不可触发。
- 错误信息不暴露异常堆栈，必须给出下一步动作；技术详情进入日志或可展开区域。
- 离线期间默认不排队重放写操作；若业务需要离线写入，必须单独 ADR 和 Issue。
- 长任务超过 1 秒提供进度，超过 5 秒默认可取消；阈值可按项目实测调整。
- 每个 Surface 在自己的变体段列出适用状态；不适用状态必须写理由。
