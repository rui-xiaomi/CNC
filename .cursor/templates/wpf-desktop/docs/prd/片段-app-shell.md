# PRD 片段：Surface 清单 › `app-shell`（主窗口整体框架）

> **用法**：贴进 PRD Issue 的 `### Surface 清单`，**必须是第一条**。所有功能 Surface 的 UI 设计描述只写内容区差异，引用本条壳层规格，不重复描述导航与状态栏。
> **UI 模式**：`spec-driven`——本描述即编码的唯一权威来源，不提供 PNG 设计稿。

---

| 项 | 值 |
|---|---|
| **surface-id** | `app-shell` |
| **兼容 page-id** | `app-shell` |
| **Surface 类型** | `Window / App Shell` |
| **标题** | 主窗口 |
| **platform-id** | `windows-desktop` |
| **Owner / 模态性** | 无 Owner / 非模态根窗口 |
| **生命周期** | 应用启动创建；关闭前处理 `dirty`、`busy` 与托盘策略 |
| **覆盖用户故事** | 全端导航与布局支撑（不直接映射单条 `US-n`） |

## UI 设计描述

### 整体结构

```
┌─────────────────────────────────────────────────────────┐
│ [图标] 应用名 · 当前模块名          [—] [□] [×]          │  ← 标题栏 32px
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  导航区   │                内容区                         │
│  240px   │              （视图宿主）                      │
│          │                                              │
│  ────── │                                              │
│  设置     │                                              │
│  用户     │                                              │
├──────────┴──────────────────────────────────────────────┤
│ ● 已连接   │  后台任务指示   │        用户名 · v1.0.0     │  ← 状态栏 28px
└─────────────────────────────────────────────────────────┘
```

### 区域规格

| 区域 | 控件 | 尺寸 | 说明 |
|---|---|---|---|
| 窗口 | `ui:FluentWindow` | 见 DESIGN.md §1.1 | 禁止用原生 `Window` |
| 标题栏 | `ui:TitleBar` | 高 32 | 含应用图标、标题、系统按钮 |
| 导航区 | `ui:NavigationView`（`PaneDisplayMode="Left"`） | 展开 240 / 折叠 48 | 见下 |
| 内容区 | `NavigationView` 的内容宿主 | 自适应 | 内边距 16 |
| 状态栏 | 自定义 `Grid`（三列） | 高 28 | 见下 |

### 标题栏

- 左：应用图标 + 应用名 + `·` + **当前模块名**（随导航选中项变化）
- 右：系统最小化 / 最大化 / 关闭按钮（由 `ui:TitleBar` 提供）
- 有未保存修改时，标题追加 ` *`（见 DESIGN.md §7 `dirty`）
- 标题文本须绑定 ViewModel 属性，不在 code-behind 拼接

### 导航区

**主导航项**（一级功能模块，≤10 项，按业务优先级排序）：

- 每项 = `ui:SymbolIcon` + 文本，高 40
- 选中态：左侧 3px 主色指示条 + 背景 `ControlFillColorDefaultBrush`
- 折叠态（宽 48）：仅图标，ToolTip 显示完整名称
- **无权限的模块直接隐藏，不显示为禁用**——避免暴露系统能力边界

**底部固定项**（`NavigationView.FooterMenuItems`）：

- 设置
- 当前用户（点击展开：切换账号 / 注销 / 关于）

**滚动**：主导航项超过可视高度时区域内滚动，底部固定项始终可见。10 项以内在最小窗口高度（640）下不会触发滚动。

**折叠触发**：
- 窗口宽度 < 1100 → 自动折叠为图标态
- 用户手动折叠/展开的选择须持久化，且**优先于**自动折叠（用户显式展开后，窗口变窄不再自动折叠，直到重启）

### 内容区

- 单一视图宿主，同一时刻只显示一个模块视图
- 切换模块时若当前视图为 `dirty`，按 PRD 状态策略拦截（保存 / 放弃 / 取消）
- 内容区**自身不显示** `loading` / `empty` / `error`——这些由各功能视图在自己范围内处理
- 窗口宽度 > 1600 时，是否分栏由**各功能视图自行决定**，壳层不干预

### 状态栏（三列）

| 列 | 内容 | 行为 |
|---|---|---|
| 左 | 连接状态指示：`●` + 文本 | 已连接=成功色 / 离线=危险色 + "已离线"。点击可手动重连 |
| 中 | 后台任务指示 | 有 `busy` 任务时显示任务名 + `ui:ProgressRing`（小号）；无任务时留空 |
| 右 | 当前用户名 · 版本号 | 静态 |

**规则**：连接状态指示**常驻**，不可关闭——顶部横幅会被用户划走，状态栏是最后的可见凭据。

## 变体段（对齐 PRD「状态策略」）

| 状态 | 壳层表现 |
|---|---|
| `default` | 状态栏左列绿点"已连接"；无横幅 |
| `offline` | 状态栏左列红点"已离线"；内容区顶部插入 `ui:InfoBar`（Severity=Error，可关闭）；导航仍可切换；所有模块内的提交操作由各视图自行禁用 |
| `offline` → 恢复 | `ui:InfoBar` 切为 Severity=Success"连接已恢复"，3 秒后自动消失；状态栏左列恢复绿点 |
| `busy` | 状态栏中列显示任务名 + 加载指示；导航**不锁定**（长任务不应阻止用户看别的模块） |
| `dirty` | 标题栏追加 ` *`；切换导航项时弹三选一确认 |
| `readonly` | 壳层无变化（只读是视图级概念，不上升到壳层） |
| `loading` / `empty` / `error` / `disabled` / `validating` | **壳层不适用**——由各功能视图在内容区内处理 |

## 验收标准（供 `/to-issues` 生成 UI Issue 时引用）

### 功能（可测试 — CI / TDD）

- 启动后窗口尺寸为 1280×800，位置居中；二次启动恢复上次位置与尺寸
- 上次记忆的显示器不存在时，回落到主显示器居中
- 点击任一导航项，内容区切换到对应视图，标题栏模块名同步更新
- 无权限的模块不出现在导航列表中
- 窗口宽度拖至 < 1100 时导航自动折叠；用户手动展开后，再次拖窄不再自动折叠

### UI 行为（可测试 — CI / TDD）

- 折叠态下每个导航项的 ToolTip 非空且等于其完整名称
- 连接断开后 10 秒内，状态栏左列变为红点"已离线"，且 `ui:InfoBar` 出现
- 连接恢复后，`ui:InfoBar` 变为成功态并在 3 秒后 `IsOpen=false`
- 当前视图为 `dirty` 时点击其他导航项，弹出确认对话框且内容区未切换
- 有后台任务时状态栏中列显示任务名，导航项 `IsEnabled` 仍为 `true`

### 设计 QA（PR 人工）

- 100% / 125% / 150% / 200% 四档 DPI 下截图，导航文本不截断、状态栏不重叠
- 浅色 / 深色两套主题截图，`ui:` 与 `hc:` 控件的语义色一致（验证 ADR-0001 的桥接生效）
- 最小尺寸 1024×640 下，导航底部固定项仍完整可见

## 实现提示

- 测试接缝取 `ShellViewModel`，断言 `CurrentModuleName`、`IsPaneOpen`、`ConnectionState`、`IsDirty` 等可观察属性
- UI 自动化（FlaUI / WinAppDriver）依赖 `AutomationProperties.Name`——**每个导航项和状态栏元素都必须设置**，否则第二组验收标准无法自动化
- 连接状态由单一 `IConnectionMonitor` 服务广播，壳层与各视图订阅同一来源，禁止各自轮询
