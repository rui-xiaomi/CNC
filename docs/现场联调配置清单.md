# 现场联调前配置清单

> 对照仓库默认（演示态）与现场必改项。带 **待真机验证** 的项未在现场实测前不得勾「完成」。  
> 详细联调顺序见 `task_plan.md` Phase 6；演示步骤见 `docs/演示实操手册.md`。

## 0. 当前仓库默认 vs 现场目标

| 配置键 | 仓库演示默认 | 现场应设 | 备注 |
|--------|--------------|----------|------|
| `App.Database.Server` | `localhost` | 现场 MySQL IP/主机名 | |
| `App.Database.Password` | 本机明文（勿提交） | 现场口令；建议 `PasswordProtected=true` + DPAPI | **禁止把明文口令 push 到 git** |
| `App.Plc.UseSimulator` | `true` | **`false`** | true 时忽略 DB 中 PLC IP，打到 127.0.0.1:15xxx |
| `App.Rcs.UseSimulator` | `true` | **`false`** | true 时本机假 RCS |
| `App.Rcs.BaseUrl` | `http://127.0.0.1:8090` | 真实 RCS HTTP 基址 | 也可 RCS 页写入 DB（`MAS_AUTO_WORKLINE_AGV` 优先） |
| `App.Rcs.ClientCode` | `CNC` | RCS 分配值 | |
| `App.Rcs.CallbackHost` | `0.0.0.0` | 监听可用 `0.0.0.0`；报备给 RCS 的须是**可达本机 IP** | 改 Host/Port 后**必须重启** |
| `App.Rcs.CallbackPort` | `9080` | 与 RCS 登记一致 | 防火墙入站放行 |
| `App.Rcs.WaterMonitorEnabled` | `false` | 首轮保持 **`false`** | 绑定/LOCATION_MAP 验完再开 |
| `App.Rcs.InventoryAutoEnabled` | `false` | 首轮保持 **`false`** | |
| `App.Rcs.SimulatorNgRate` | `0.3` | 现场无关（模拟器关）；演示想全 OK 可改 `0` | |
| `App.Rcs.SchedulerEnabled` | `true` | 首轮可先 `false` 验 PLC/RCS，再开自动 | |
| `App.Rcs.ReconcileRetryIntervalMs` | `5000` | 保持正整数；对账失败后台重试间隔 | `<=0` 启动校验失败 |
| `App.Rcs.HasMatRecheckFailThreshold` | 默认 `6`（未写入演示 json 时用代码默认） | 连续 HasMat 未知达阈 → Alarm | 勿当无料放行 |
| `App.Logging.MinimumLevel` | `Information` | 排障临时 `Debug` | |
| `App.Logging.PersistSuccessfulReads` | `false` | 排障点位临时 `true`，完后改回 | |
| `App.Logging.DeviceLogRetentionDays` | `14` | 可按磁盘调 | `≤0` 关闭清理 |

## 3. 数据库业务配置（比改 json 更关键）

- [ ] `MAS_AUTO_WORKLINE_PLC`：真实 IP、端口、`PLC_READ_WAY`（ModbusTCP / FINS）— **待真机验证**

- [ ] `MAS_AUTO_PLC_POINT`：与 `docs/测试机信号表.md` 一致 — **待真机验证**
- [ ] `MAS_AUTO_LOCATION_MAP`：现场搬运 cell（10层×左右2：上料 101101/101102…1011001/1011002；中转 301/302、下料 303、NG 401 同规则；内长宽 201101/201102）+ 对应 shelf；**不要**把 `LOAD_AREA`/`UNLOAD_AREA` 写成 101/301
- [ ] `MAS_AUTO_FRAME_BIND`：上料/下料/中转(2)/NG(3) 齐全
- [ ] `MAS_AUTO_FRAME_SLOT`：槽位与物理一致（勿用演示补料 SQL 覆盖生产数据）

## 4. 启动后日志自检（`logs/cncloader-yyyyMMdd.log`）

应看到类似含义（措辞以实际日志为准）：

- [ ] RCS 配置已从库加载（或种子落库）
- [ ] 回调服务已启动 `…:9080/externalApi/`（非启动失败）
- [ ] **RCS 模拟器未启用** / **CNC 机台行为模拟器未启用**
- [ ] PLC 建链为真实 IP，不是 `127.0.0.1:15xxx`
- [ ] 「启动对账完成，开始自动派工」（若 `SchedulerEnabled=true`）

## 5. 联调顺序提醒（配置就绪后）

① 网络回调 → ② PLC 逐点（待真机）→ ③ RCS 单任务 → ④ 单工位慢速 → ⑤ 并行+异常 → ⑥ 换架/盘点 → ⑦ §11 签字  

排障开细日志后务必改回，避免磁盘/库再胀。
