# 智造云枢 LineOS — UI 设计文档（现代工业 · WPF-UI + HandyControl）

> 适用于 `客户端开发文档.md` 描述的 **智造云枢 LineOS**（WPF / .NET 8）工业客户端。UI 底座：**WPF-UI 4.3（FluentWindow 外壳 + NavigationView 导航 + 明暗主题）+ HandyControl 3.5（业务控件）**。配套高保真原型：`prototype/index.html`（浏览器直接打开，可点击切换页面）。标题栏品牌文案为「智造云枢 LineOS」。
>
> 设计基线（经 ui-ux-pro-max 方法论选型）：**风格 = 现代工业控制系统 / HMI 仪表盘**；**主题 = 深色优先、可切浅色**；**字体 = Inter（界面）+ JetBrains Mono（机器数据）**；**配色 = 石墨深色面 + 青teal 强调 + 状态色编码（色 + 形双通道）**。

---

## 1. 设计目标与方向

这是一套**工厂现场长时间值守**的尺寸检测计量站控制软件——三台测量机（内长宽 / 平面度 / A基准）、每台两个并行治具、判定语言是 **go/no-go（OK/NG）**。设计目标：信息密度高、状态一眼可辨、误操作成本低、长时间注视不疲劳。

方向定位：**现代工业控制系统（modern industrial HMI）**，明确区别于两端——

| 不要（传统 ERP 后台） | 不要（消费级 Fluent / SaaS） | 我们要（现代工业 HMI） |
| --- | --- | --- |
| 灰底 + 密集网格 + 系统默认控件 | 圆角大卡片层叠、亚克力/Mica 装饰、彩色渐变 | 石墨深色工作面 + 克制强调色 + 数据驱动 |
| 千篇一律的表单堆叠 | 营销式大留白、居中大标题 | 紧凑网格、左对齐、信息优先 |
| 弹窗 alert / 状态靠文字 | emoji 图标、入场动画炫技 | 状态色 + 形状双编码、150–200ms 微过渡 |

把方向钉在主题上：视觉借用**现代计量/SCADA 上位机**的语汇——深色仪表面、青色强调、等宽读数、卡片化机台单元。**签名元素（全局仅此一处张力）**：监控看板的机台治具卡——卡头一条细 accent 刻度 hairline（计量量具母题），治具行用大号等宽 OK/NG 判定。其余页面保持安静克制，不重复张力。

**明确禁止的"AI 生成感"**：紫色/彩色渐变背景、玻璃拟态堆叠、emoji 图标、视差/入场动画、霓虹光晕、装饰性阴影制造悬浮、装饰波形底纹。

## 2. 设计令牌（Design Tokens）

WPF 落地：颜色 → `SolidColorBrush`，间距 → `Thickness`/`Double`，圆角 → `CornerRadius`，以 `ResourceDictionary` 覆盖 WPF-UI / HandyControl 默认主题资源。深色为默认主题，浅色复用同名 token 仅换值。

### 2.1 颜色（深色优先，附浅色）

| 用途 | Token | 深色 | 浅色 | 说明 |
| --- | --- | --- | --- | --- |
| 应用底 | `bg` | `#0E1116` | `#F5F7FA` | 窗口工作区背景 |
| 面板 | `surface` | `#161B22` | `#FFFFFF` | 卡片/表格/表单容器 |
| 面板·抬升 | `surface-2` | `#1C232B` | `#F0F3F7` | 选中行、内嵌区、表头 |
| 边框/分隔 | `border` | `#2A323B` | `#E2E6EB` | 主要层级手段（1px 实线） |
| 主文字 | `fg` | `#E6EAF0` | `#0F172A` | 对比 ≥ 12:1 |
| 次要文字 | `fg-muted` | `#8B95A1` | `#5B6573` | ≥ 4.5:1 |
| 强调（主操作/选中/链接） | `accent` | `#16C2C7` | `#0E8E92` | teal-cyan，仪器母题 |
| 状态·OK/正常 | `ok` | `#22C55E` | `#15803D` | 形：实心圆 ● |
| 状态·运行/检测中 | `run` | `#3B82F6` | `#1D4ED8` | 形：三角 ▶ |
| 状态·警告 | `warn` | `#F59E0B` | `#B45309` | 形：菱形 ◆ |
| 状态·报警/NG | `alarm` | `#EF4444` | `#DC2626` | 形：方块 ■ |
| 状态·离线/禁用 | `idle` | `#6B7280` | `#9AA1AA` | 形：空心圆 ○ |

**状态不只靠颜色**：每个状态徽章 = 颜色 + 形状 + 文字（OK / NG / 运行 / 警告 / 离线），满足色盲可达性。强调色 `accent` 只用于交互态（选中/主按钮/焦点/链接），不与状态色混用。

### 2.2 字体

两档刻意搭配（比旧三档更现代、更克制）：

| 角色 | 字体 | 字号 | 用途 |
| --- | --- | --- | --- |
| 界面 | **Inter**（回退 Segoe UI Variable / Segoe UI） | 13px 正文 / 12px 辅助 / 15–18px 标题 | 导航、表格、表单、标题、说明 |
| 机器数据 | **JetBrains Mono**（回退 Consolas） | 11–28px | 寄存器 `D1006`、`OK/NG`、计数、时间戳、心跳、IP |

- 等宽字体用于一切机器数据，保证列对齐、便于比对——这是工业界面区别于普通后台的关键细节。
- 字体随程序打包（`.ttf` 作应用资源，`pack://` 引用），不依赖系统已装。旧设计的 Saira 标牌体在现代方向下移除。

### 2.3 形状 / 间距 / 高度 / 动效

- 圆角：面板/卡片 `radius-md: 6px`；输入/按钮 `radius-sm: 4px`；徽章 4px。比旧 3px 略大，取现代感但不圆润。
- 边框：`1px solid border`，深色下是主要分层手段（不靠阴影堆叠层级）。
- 间距刻度：`4 / 8 / 12 / 16 / 24`；面板内边距 12–16px；卡片间距 12px。
- 高度：表格行 `36px`（比旧 32 略松，现代呼吸感）；按钮 32px；状态条 44px；标题栏 40px。
- 阴影：仅浮层/弹窗/下拉 `0 8px 24px rgba(0,0,0,.45)`（浅色 `.16`）；常规面板**无阴影**。
- 动效：仅 150–200ms 的颜色/透明度过渡；运行态可用 ≤1s 呼吸；尊重 `prefers-reduced-motion`。

## 3. 底座与控件映射（WPF-UI + HandyControl）

职责严格切分（与 `客户端开发文档.md` §1.4 一致）：**WPF-UI 负责外壳/导航/主题，HandyControl 负责业务控件，自研 token 覆盖两库配色**。

| 需求 | 库 | 控件 / 用法 |
| --- | --- | --- |
| 窗口外壳、标题栏、最小/最大/关闭 | WPF-UI | `FluentWindow` + `TitleBar`（关闭 Mica，用 `surface` 实色，工业平面感） |
| 左侧导航 | WPF-UI | `NavigationView`（图标 + 文字，可折叠为图标条；分组：运行 / 配置 / 设备 / 物流） |
| 明暗主题切换 | WPF-UI | `ApplicationThemeManager`（默认 Dark，标题栏提供切换） |
| 主按钮 / 次按钮 | WPF-UI | `ui:Button`（主操作 `Appearance=Primary` 映射到 `accent`） |
| 危险操作（写 PLC / 删除） | WPF-UI + HandyControl | 红色描边按钮 + `HandyControl Dialog` / `ui:ContentDialog` 二次确认 |
| 数据表 | HandyControl | `DataGrid`（重定义表头/行样式；数值列右对齐 + 等宽；状态徽章列） |
| 分页 | HandyControl | `Pagination`（长列表，如点位/记录） |
| 表单输入 | HandyControl | `TextBox` / `ComboBox` / `NumericUpDown` / `DatePicker` / `PasswordBox`，`InfoElement` 做标签与校验提示 |
| 报警 / 操作提示 | HandyControl | `Growl`（右上角堆叠；报警红、成功绿、信息蓝，可手动确认） |
| 弹窗 / 抽屉 | HandyControl | `Dialog` / `Drawer`（点位映射编辑、料架槽位录入） |
| 卡片容器 | WPF-UI | `ui:Card` 作机台单元/KPI 容器基座，自研 token 覆盖描边圆角 |
| 图标 | WPF-UI | `SymbolIcon`（Fluent 线性图标，禁用 emoji） |
| 连接状态灯 / 徽章 | 自研 | `Ellipse`/`Path` + 文本，色 + 形双编码 |

要点：两库都会全局重定义原生控件隐式样式，统一以 **HandyControl 作业务控件基线**，自研 `Styles` 对需覆盖的控件用 `x:Key` 显式覆盖；WPF-UI 仅作用于外壳/导航作用域；资源字典加载顺序 `WPF-UI → HandyControl → 自研 token`（自研最后，覆盖两库）。

## 4. 布局骨架

`FluentWindow` 三段式，导航用 `NavigationView`（非树形，扁平分组）：

```
┌────────────────────────────────────────────────────────────┐
│ TitleBar：应用名 · 线体下拉 · PLC在线 N/M · 告警计数 · 主题切换 · 窗口控件 │
├──────────┬─────────────────────────────────────────────────┤
│Navigation│ 状态条(44)：当前页标题 · 协议 ModbusTCP · 心跳 · 时钟  │
│View 导航 │─────────────────────────────────────────────────┤
│ 运行      │                                                 │
│ ·监控看板 │            内容区（页面切换，ContentPresenter）     │
│ 配置      │                                                 │
│ ·线体     │                                                 │
│ ·工序     │              Growl 报警在右上角堆叠               │
│ ·机台     │                                                 │
│ 设备      │                                                 │
│ ·PLC管理  │                                                 │
│ ·AGV     │                                                 │
│ ·扫码枪   │                                                 │
│ 物流      │                                                 │
│ ·料架     │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

- **导航**：`NavigationView` 分组扁平菜单，无展开/折叠树。当前项左 3px accent 条 + 背景 `surface-2`。点位映射归入 PLC 管理页内 tab，不单列。
- **标题栏**承载全局上下文：当前线体、PLC 在线数（N/M）、未处理告警计数、主题切换、窗口按钮。
- **状态条**：每页顶部固定，显示页名、协议、心跳（等宽）、系统时间。

## 5. 组件规范

| 组件 | 规范 |
| --- | --- |
| 按钮·主操作 | 实心 `accent`、白字、高 32px、圆角 4px、hover 加深 8%、禁用降透明 |
| 按钮·次要 | `surface-2` 底 + `border`，文字 `fg` |
| 按钮·危险（写 PLC/删除） | 描边/文字 `alarm`，点击弹 HandyControl Dialog 二次确认 |
| 数据表 | 表头 `surface-2`、sticky；行高 36px；行 hover 浅 accent 染色；无斑马纹，靠 1px 边框分隔；数值列右对齐 + 等宽；状态列用徽章 |
| 表单 | 标签在左（固定 96px）输入在右；行距 8px；必填 `*`；校验错误用 HandyControl `InfoElement` 在字段下方红字 |
| 状态徽章 | 形 + 色 + 文：`● OK` / `■ NG` / `▶ 运行` / `◆ 警告` / `○ 离线` |
| KPI 磁贴 | `ui:Card`：标签（Inter 12px muted）+ 大号等宽数字 + 状态色；无渐变无插画 |
| 机台单元卡 | `ui:Card`：卡头（机台名 + 门/安全指示灯）+ accent 刻度 hairline + 两个加工位行（徽章/工件/计数）|
| 下拉（建层级关联） | HandyControl `ComboBox`，用于"所属线体/所属工序/所属 PLC" |
| 浮层/弹窗 | 唯一允许阴影处；遮罩 `rgba(0,0,0,.5)`（浅色 `.32`）|
| 报警提示 | HandyControl `Growl` 右上角堆叠，红/绿/蓝按等级，可确认 |
| 图标 | WPF-UI `SymbolIcon` 线性图标，继承文字色；禁用 emoji |

## 6. 各页设计要点

### 6.1 监控看板
- **一屏布局**（对齐 `docs/prototype`）：区域间距 8、卡片间距 12；KPI → 产线流 → 主区（左机台 / 右记录+告警），尽量不滚动。
- **视觉**：清晰描边分层（无阴影/霓虹）；看板专用提亮面色与描边（`DashSurface` / `DashBorder`）；状态矢量图标（色+形+文）；空闲工位用干净 `Surface2`，运行/OK/NG 再用 soft tint。
- **签名元素**：机台卡顶栏校准刻度 hairline；治具行判定态（OK/NG/ALM）大号等宽着色字，非判定态为图标+状态文案。
- 顶部 4 个 KPI（在线机台 / 工位 OK / 工位 NG / 未处理告警），24px 等宽数字 + 副文案 + 语义图标。
- **产线流**：左侧线体头（产线流 + LINE 码）→ 站点卡（顶色条 + 名/EQ + 状态图标 + 双槽 seg）→ `›››` 连接 → 末端分叉（**NG出站实心橙块 / 下料出站实心绿块**，深色字；对应出口激活时整卡透明度呼吸闪）；点击机台节点高亮下方机台卡。
- 左栏机台卡：中文名主标题 + EQ Mono 徽章；门/安全图标；工位行左色条 + 物料码；报警保留「恢复」。
- 左栏机台卡 **UniformGrid 均分等高**（工位数不同也拉满卡片高度）；右栏上「最近加工记录」与下「实时告警」近均分（约 1.1:1）。
- 右栏记录表列宽保证工位/结果/耗时不截断，物料列可省略并带 Tooltip。
- 数据来自 PLC 标准状态；物料码由调度器透出到 `PositionStatus` 物料字段。

### 6.2 线体 / 工序 / 机台管理（三个独立页面）
- 统一"左列表（DataGrid）+ 右编辑表单"双栏式。
- 工序页含"所属线体"下拉；机台页含"所属工序"+"所属 PLC"下拉——**用下拉建层级，不用树**。
- 机台页下方挂"加工位（2）"子表与"关联料架"入口。长列表用 HandyControl Pagination。

### 6.3 PLC 管理（核心，含点位映射 tab）
- 顶部连接条：IP/端口输入 + 连接/断开 + 心跳灯 + 协议（ModbusTCP / FINS，随该 PLC 配置）。
- "读"面板：点位表（机台/加工位/信号/寄存器/原始值/语义值），单次读或周期轮询；ON 绿 OFF 灰，数值等宽。
- "写"面板：仅可写信号（测试启动），选值 1/2 → 下发（危险按钮 + Dialog 二次确认）→ 回读校验；底部操作流水。
- "点位映射" tab：可视化维护 `MAS_AUTO_PLC_POINT`，支持从信号表批量导入某机台一组点位。

### 6.4 AGV / 扫码枪管理（仅测试）
- 极简单页：连接参数 + "测试连接"按钮 + 结果区（连通/超时/原始报文，等宽显示）。扫码枪页额外显示"最近一次扫码内容"。

### 6.5 料架管理
- 上：料架列表（名称/识别码/槽位数）。
- 中：选中料架的**绑定关系**（机台 + 角色：上料/下料），明确展示"一架两用"。
- 下：**分层槽位网格**，按层分行展示（如上料架 2 层 × 5），每格显示"层-位"与物料 ID，空/占用以状态色 + 形状区分；**初始入库允许不放满**。顶部"物料反查"输入框，输入物料 ID 高亮其所在料架与层位。

## 7. 可达性与交付清单

- 文本对比 ≥ 4.5:1（正文）/ ≥ 3:1（大字与图标）；状态不靠颜色单一表达（色 + 形 + 文）。
- 全键盘可达：Tab 顺序合理，焦点环 2px `accent` 可见；NavigationView/表格/表单均可键盘操作。
- 所有可点元素有 hover 反馈与指针态；写操作禁用态明确。
- 过渡 150–200ms，仅颜色/透明度，尊重减少动效偏好。
- 图标全部矢量（WPF-UI SymbolIcon / 看板自研 Path Geometry）；无 emoji；无装饰渐变；无玻璃拟态堆叠；无霓虹光晕与装饰阴影。
- 深色为默认（现场夜班/抗眩光）；浅色复用同套 token 仅换背景/前景，状态色不变。

> WPF 落地映射：本文 token → `ResourceDictionary`（覆盖 WPF-UI/HandyControl 默认）；组件规范 → `Style`/`ControlTemplate`；原型 HTML 仅用于**视觉与交互验收**，用 CSS 模拟目标观感，不是最终代码。
