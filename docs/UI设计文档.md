# 客户端 UI 设计文档

> 适用于 `客户端开发文档.md` 描述的 WPF / .NET 10 工业客户端。配套高保真原型：`prototype/index.html`（浏览器直接打开，可点击切换 8 个页面）。
>
> 设计基线由 ui-ux-pro-max 选型得出：**风格 = 数据密集仪表盘（Data-Dense Dashboard）+ 瑞士极简（Swiss/Minimalism）**；**字体 = Inter（界面）+ 等宽字体（寄存器/数值）**；**配色 = 工业中性灰 + 状态色编码**。

---

## 1. 设计目标与"去 AI 味"原则

这是一套**工厂现场长时间值守**的控制软件，不是营销网站。设计目标：信息密度高、状态一眼可辨、误操作成本低、长时间注视不疲劳。

明确**禁止**以下"AI 生成感"特征：

| 禁止 | 改用 |
| --- | --- |
| 紫色/彩色渐变背景、玻璃拟态、霓虹光晕 | 纯色中性背景 + 1px 实线边框 |
| 居中大标题 + 副标题的"落地页"排版 | 左对齐、紧凑信息栏，标题小而克制 |
| 圆角卡片层层堆叠、大留白 | 3px 小圆角、网格化面板、紧凑间距（8/12px） |
| emoji 当图标 | 统一线性 SVG 图标（24×24，1.5px 描边） |
| 阴影制造悬浮感 | 以边框和分隔线建立层级，阴影仅用于浮层/弹窗 |
| 动效炫技（视差、入场动画） | 仅 150–200ms 状态过渡；尊重 `prefers-reduced-motion` |
| 装饰性插画、渐变 KPI 卡 | 数字优先，等宽字体对齐，状态色点缀 |

一句话：**像示波器/SCADA 上位机，不像 SaaS 官网。**

### 1.1 设计方向与签名元素（frontend-design）

把方向钉在主题本身：这是**线边 CNC 尺寸检测计量站**——三台测量机（内长宽 / 平面度 / A基准）、每台两个并行治具、判定语言是 **go/no-go（OK/NG）**。视觉直接借用计量仪器的语汇，而非通用后台。

- **方向**：计量仪表盘面板（instrument panel）。冷调钢灰工作面、仪器深灰外框、等宽数据、校准刻度线。
- **签名元素（全局只此一处张力）**：监控看板的**机台治具卡 = 仪器读数单元**——卡头下方一条"校准刻度"hairline 标尺（计量量具的视觉母题），治具行用大号等宽 OK/NG 判定。其余页面一律保持安静、克制，不重复张力。
- **刻意回避 AI 三大默认**：奶油底+衬线+陶土色、近黑底+单一荧光色、报刊式发丝栏。本方案走"冷钢仪器"路线，与三者都不同。

## 2. 设计令牌（Design Tokens）

WPF 中以 `ResourceDictionary` 落地（颜色 → `SolidColorBrush`，间距 → `Thickness`/`Double`，圆角 → `CornerRadius`）。

### 2.1 颜色

| 用途 | Token | 值 | 说明 |
| --- | --- | --- | --- |
| 应用外框/标题栏 | `--chrome` | `#1E2329` | 深色窗口 chrome + 侧栏 |
| 侧栏文字 | `--chrome-fg` | `#C7CDD4` | |
| 工作区背景 | `--bg` | `#F4F5F7` | 浅中性灰，抗眩光 |
| 面板背景 | `--surface` | `#FFFFFF` | |
| 边框/分隔 | `--border` | `#D6D9DE` | 主要层级手段 |
| 主文字 | `--fg` | `#1A1D21` | 对比 ≥ 12:1 |
| 次要文字 | `--fg-muted` | `#5B6168` | ≥ 4.5:1 |
| 主操作色 | `--accent` | `#1B6EC2` | 按钮/选中/链接 |
| 状态·正常/OK | `--ok` | `#16A34A` | |
| 状态·运行 | `--run` | `#2563EB` | |
| 状态·警告 | `--warn` | `#D97706` | |
| 状态·报警/NG | `--alarm` | `#DC2626` | |
| 状态·离线/禁用 | `--idle` | `#6B7280` | |

状态**不只靠颜色**：每个状态徽章同时带文字（OK / NG / 运行 / 报警 / 离线）与形状（实心圆/空心圆/方块），满足色盲可达性。

### 2.2 字体

三档刻意搭配，不是"全用 Inter"的默认做法：

| 角色 | 字体 | 字号 | 用途 |
| --- | --- | --- | --- |
| **签名/标牌层** | Saira Semi Condensed（回退 Segoe UI） | 12–16px | 标题栏、导航分组、面板标题、表头、KPI 标签——工业标牌的窄体气质 |
| 界面正文 | Inter（回退 Segoe UI） | 13px | 表格单元、表单、说明文字 |
| **机器数据** | JetBrains Mono（回退 Consolas） | 11–28px | 寄存器 `D1006`、`OK/NG`、计数、时间戳、心跳 |

- 窄体 Saira 只用于"标牌/标签"层，给密集界面一层工业识别度；正文留给中性的 Inter 保证可读。
- 等宽字体用于一切机器数据，保证列对齐、便于比对——这是工业界面区别于普通后台的关键细节。
- WPF 落地：三款字体可作为应用资源（`.ttf`）随程序打包，`FontFamily` 引用 `pack://` 资源，避免依赖系统已装字体。

### 2.3 形状与间距

- 圆角：`--radius: 3px`（输入/按钮/面板统一）；徽章 2px。
- 边框：`1px solid var(--border)`，是主要分层手段。
- 间距刻度：4 / 8 / 12 / 16（密集网格，面板内边距 12px）。
- 阴影：仅弹窗/下拉 `0 4px 16px rgba(0,0,0,.16)`；常规面板无阴影。
- 行高：表格行 32px，紧凑；正文 1.5。

## 3. 布局骨架

桌面三段式，**不使用树形导航**（按需求：各管理页为独立页面）：

```
┌────────────────────────────────────────────────────────────┐
│  标题栏 chrome：应用名 · 线体选择下拉 · 连接/心跳灯 · 窗口控件   │
├──────────┬─────────────────────────────────────────────────┤
│ 侧栏导航  │  顶部状态条：当前页标题 · PLC状态 · 告警计数 · 时间    │
│ (扁平列表)├─────────────────────────────────────────────────┤
│ · 监控    │                                                 │
│ · 线体管理 │            内容区（页面独立切换）                  │
│ · 工序管理 │                                                 │
│ · 机台管理 │                                                 │
│ · PLC管理 │                                                 │
│ · AGV管理 │                                                 │
│ · 扫码枪   │                                                 │
│ · 料架管理 │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

- **侧栏**：扁平单层菜单项（8 项），无展开/折叠树，无父子缩进。当前项左侧 3px 高亮条 + 背景加深。
- **标题栏**承载全局上下文：当前线体、PLC 连接状态灯（绿/红）、心跳计数。
- **状态条**：每页顶部固定，显示页名、关键全局指标、系统时间。
- WPF 实现：`Window` 去原生边框（`WindowStyle=None` + 自绘标题栏）；主体 `Grid` 两列；导航用 `ListBox` + `ItemTemplate`；内容区用 `ContentControl` + 页面切换（不是 `TreeView`）。

## 4. 组件规范

| 组件 | 规范 |
| --- | --- |
| 按钮·主操作 | 实心 `--accent`，白字，高 30px，圆角 3px，hover 加深 8%，禁用降透明 |
| 按钮·次要 | 白底 + 边框，文字 `--fg` |
| 按钮·危险（写 PLC/删除） | 边框/文字 `--alarm`，点击需二次确认弹窗 |
| 数据表 | 表头浅灰 `#EDEFF2`、sticky；行高 32px；行 hover `#F0F4FA`；斑马纹关闭，靠边框区分；数值列右对齐 + 等宽字体 |
| 表单 | 标签在左（90px 固定宽）输入在右；行距 8px；必填项标 `*`；校验错误在字段下方红字 |
| 状态徽章 | 圆点 + 文案：`● 运行` / `● OK` / `○ 离线` / `■ 报警`；颜色见 2.1 |
| 面板 Panel | 白底 + 1px 边框；标题栏 32px（左标题、右操作）；无阴影 |
| 下拉（建立层级关联） | 标准 `ComboBox`，用于"所属线体/所属工序"选择 |
| 浮层/弹窗 | 唯一允许阴影处；遮罩 `rgba(0,0,0,.32)` |
| 图标 | 线性 SVG，24×24，1.5px 描边，继承文字色；禁用 emoji |

## 5. 页面设计要点

### 5.1 监控看板
- 顶部 4 个 KPI（运行机台数 / 当班 OK / 当班 NG / 未处理告警），数字大、等宽、状态色。
- 机台网格：每台机台一个面板，含门/安全两个机台级指示灯 + **两个加工位行**（状态徽章、当前工件或电极、计数）。两加工位并行、独立显示。
- 右侧告警列表：时间（等宽）+ 等级色条 + 描述 + 确认按钮。
- 数据来自 PLC 信号合成的标准状态（见开发文档 §3.4）。

### 5.2 线体 / 工序 / 机台管理（三个独立页面）
- 统一"左列表表格 + 右编辑表单"或"上表格 + 下表单"双栏式。
- 工序页含"所属线体"下拉；机台页含"所属工序"下拉——**用下拉建立层级，不用树**。
- 机台页下方挂"加工位（2）"子表与"关联料架"入口。

### 5.3 PLC 管理（核心）
- 顶部连接条：IP/端口输入 + 连接/断开 + 心跳灯 + 协议（ModbusTCP）。
- 左"读"面板：点位表（机台/加工位/信号/寄存器/原始值/语义值），可单次读或周期轮询；数值等宽、ON 绿 OFF 灰。
- 右"写"面板：仅可写信号（测试启动），选值 1/2 → 下发（危险按钮 + 二次确认）→ 回读校验；底部操作流水。

### 5.4 AGV / 扫码枪管理（仅测试）
- 极简单页：连接参数 + "测试连接"按钮 + 结果区（连通/超时/原始报文，等宽显示）。扫码枪页额外显示"最近一次扫码内容"。

### 5.5 料架管理
- 上：料架列表（名称/识别码/槽位数）。
- 中：选中料架的**绑定关系**（机台 + 角色：上料/下料），明确展示"一架两用"。
- 下：**分层槽位网格**，按层分行展示（如上料架 2 层 × 5），每格显示"层-位"与电极 ID，空/占用以状态色区分；**初始入库允许不放满**，空槽正常显示为空。顶部"电极反查"输入框，输入电极 ID 高亮其所在料架与层位（示例：电极 E03 → 上料总架 1 层 3 位）。

## 6. 可达性与交付清单

- 文本对比 ≥ 4.5:1（正文）/ ≥ 3:1（大字与图标）；状态不靠颜色单一表达。
- 全键盘可达：Tab 顺序合理，焦点环 2px `--accent` 可见。
- 所有可点元素 `cursor: pointer` + hover 反馈；写操作禁用态明确。
- 过渡 150–200ms，仅颜色/透明度，尊重减少动效偏好。
- 图标全部 SVG；无 emoji；无渐变；无玻璃拟态。
- 浅色主题为主（现场抗眩光）；可选深色主题复用同一套令牌（仅反转背景/前景，状态色不变）。

> WPF 落地映射：本文 CSS 令牌 → `ResourceDictionary`；组件规范 → `Style`/`ControlTemplate`；原型 HTML 仅用于**视觉与交互验收**，不是最终代码。
