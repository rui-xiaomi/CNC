# ADR-0004：RCS 任务能力档（上下料动词 + 整架搬运）

- 状态：Accepted
- 日期：2026-09-07

## 背景

现场目前只有复合车，工位上下料应走 `excuteTask`/`grabTask`。整架搬运（换架、空托盘回收）仍走 `transitTask`。后续现场可能改回搬运上下料，不能把三种接口做成互替的总开关。

`transitTask.taskType` 曾因现场 RCS 要求写死 `grabTask`，与抓取接口混淆。现按接口契约填 `in`/`out`/`move`。

## 决策

1. `App:Rcs:LoadUnloadVerb` = `Grab` | `Transit`，默认 `Grab`。启动校验非法值失败。只读启动项，不进 `RcsRuntimeConfig`，禁止运行中热切。
2. 工位上料/下料：有料架槽时按能力档选 `DispatchGrabAsync` 或 `DispatchTransitAsync`。命名区无槽回退固定 `transitTask`。自动下料不走工位直送；料架按一架两用（上游下料=下游上料）。
3. 换架、空托盘回收固定 `transitTask`；盘点固定 `identifyQR`。本轮不配开关。
4. `transitTask.taskType`：上料 `out`、下料 `in`、换架/空托盘/转序 `move`。`excuteTask` 的 `grabTask` / `identifyQR` 不变。
5. Redo / Redispatch / AutoRedo 按落库 `RCS_KIND` 原样重发，不读当前能力档。
6. 抓取孔位：`srcPos`/`dstPos` = `layerNo * 100 + posInLayer`（L1P1=101）。加工位孔从该位 **cell** 拆层位；两端 `position[]` 只用 station/shelf，禁止把 cell 当站码。缺 station/shelf 或无法拆孔则拒发。

## 后果

- 抓取档必须同时录入加工位 station（payload）与 cell（拆孔），以及料架 shelf + 槽 cell（预记校验）。
- 既有调度门禁单测显式 `LoadUnloadVerb=Transit`，避免默认 Grab 改写 cell 路径断言。
