# 测试机信号表

> 来源：现场 Excel 信号对照表整理。共 3 台测试机（内长宽 / 平面度 / A基准），每台含「测试机输出」与「测试机输入」两组信号。
> 备注约定：
> - 输出（信号输入类）：值 = 1 表示信号输入 ON；值 = 2 表示信号输入 OFF。
> - 输入（启动类）：值 = 1 表示启动；值 = 2 表示关闭启动信号。
>
> IO 地址说明：原始图片分辨率较低，IO 位地址按「连续分配」交叉校验得出，三台测试机输出位首尾相接、互不重叠（内长宽 `I0.0`–`I1.1`、A基准 `I1.2`–`I2.3`、平面度 `I2.4`–`I3.5`）。寄存器（D 区）地址清晰可信。请以 PLC 实际地址表为准复核。
