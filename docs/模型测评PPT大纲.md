## 第 5 页 · 测评方法与评分体系

**标题**：怎么评的？——公平、可复现

**评分维度（7 项，满分 5）**：

| 维度 | 权重 |
|------|------|
| 需求理解准确度 | 20% |
| 代码质量 | 20% |
| 首次可用率 | 15% |
| 调试与排错 | 15% |
| 跨文件一致性 | 10% |
| 文档与方案 | 10% |
| 交互效率 | 10% |

**测评原则**（4 条 bullet）：
- 同一用例、同一 `docs/` 权威文档
- 记录交互轮次、build 结果、人工修正点
- 客观（build 次数）+ 主观（工程师评分）
- 配合 Agent Skills（brainstorming / planning-with-files / ui-ux-pro-max）
