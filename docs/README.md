## 目录约定

- 开发文档统一用 Markdown，中文正文，代码/表名/字段名用英文。
- 开发方案只保留 `客户端开发文档.md` 一份，不再另起平行方案文件，避免多源不一致；数据库设计、UI 规范、信号契约各由对应专项文档单独维护，开发文档引用而不复制。
- 信号地址只允许在 `测试机信号表.md` 维护一份；其他文档引用而不复制。
- 新增章节遵循"结论先行 → 约束 → 设计 → 待确认项"的写法；待确认项统一用 `> ⚠️ 待确认` 标注。
