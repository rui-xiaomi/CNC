### 2.2 评分维度与权重

每项 **1～5 分**（1=不可用，3=可用需较多修改，5=可直接验收）。

| 维度 | 权重 | 说明 |
|------|------|------|
| **需求理解准确度** | 20% | 是否正确理解业务约束（如"仅与 PLC 通信""一机一 PLC""写操作先落流水"） |
| **代码质量** | 20% | 分层合规、命名一致、无过度设计、符合项目既有风格 |
| **首次可用率** | 15% | `dotnet build` 0 警告 0 错误、启动无异常 |
| **调试与排错能力** | 15% | 能否定位根因（如 XAML 样式错配、软删未过滤、UDP 假在线） |
| **跨文件一致性** | 10% | Core/Data/UI/Communication 多层改动是否同步 |
| **文档与方案输出** | 10% | 方案是否可执行、是否与权威文档一致 |
| **交互效率** | 10% | 轮次少、返工少、自主完成度高 |

**综合分计算公式**：

```
综合分 = Σ(维度得分 × 权重)
```

## 三、项目背景与用例地图

### 3.1 项目简介（给非技术领导）

CNC 自动化上下料客户端是部署在工位机上的 **WPF 桌面程序**，负责：

- 经 IP/TCP 与 3 台 PLC 通信（Modbus / FINS），**不直连 CNC 机台**
- 管理线体、工序、机台、料架等配置
- 后续实现双加工位并行上下料调度

当前进度：**Phase 1～3、5 已完成**，Phase 4（核心状态机）与 Phase 6（现场联调）待做。
